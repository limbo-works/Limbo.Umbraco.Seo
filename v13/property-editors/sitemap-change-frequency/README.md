# Sitemap Change Frequency

**Alias:** `Limbo.Umbraco.Seo.SitemapChangeFrequency`

The property editor allows users to select the sitemap change frequency of a given page. If selected, the property value will be exposed as an instance of `Limbo.Umbraco.Seo.Sitemaps.Models.SitemapChangeFrequency`.
